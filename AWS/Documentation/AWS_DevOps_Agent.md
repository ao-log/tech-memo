# Document

[About AWS DevOps Agent](https://docs.aws.amazon.com/devopsagent/latest/userguide/about-aws-devops-agent.html)

* 機能
  * 障害調査を自動的に実施
  * チャットで更なる障害調査
  * 軽減プランの提供
  * サポートケース起票
* 概要
  * 管理者は Agent Space を作成し各種設定を行う
  * オペレーションチームは web app にアクセスし、各種作業を行う


## Getting started with AWS DevOps Agent

[Creating an Agent Space](https://docs.aws.amazon.com/devopsagent/latest/userguide/getting-started-with-aws-devops-agent-creating-an-agent-space.html)

* Agent Space を作成する
  * DevOps Agent Role を設定する。このロールの権限が DevOps Agent がアクセスできる範囲となる
* Web App の有効化


## DevOps Agent Incident Response

[DevOps Agent Incident Response](https://docs.aws.amazon.com/devopsagent/latest/userguide/devops-agent-incident-response.html)

* Investigation Timeline にて調査のタイムラインを確認できる
* Root cause タブに根本原因の概要が表示される
* Mitigation Plan を作成してくれる
* チャットでエージェントに更なる調査を支持できる
* サポートケースを起票することも可能


[Starting Investigations](https://docs.aws.amazon.com/devopsagent/latest/userguide/devops-agent-incident-response-starting-investigations.html)

* 調査の開始方法は三つ
  * チケットシステムとの連携
  * webhook
  * 手動
